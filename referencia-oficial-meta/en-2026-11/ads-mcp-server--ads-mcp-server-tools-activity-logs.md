# Activity logs


Get visibility into activity log changes for an ad account, mirroring the Ads Manager campaign history page.

| Tool | Description |
|---|---|
| `ads_account_get_activity_logs` | Retrieve activity log entries for an ad account, optionally scoped by object, time window, event category, or user. |
