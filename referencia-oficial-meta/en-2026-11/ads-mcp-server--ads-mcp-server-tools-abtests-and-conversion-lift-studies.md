# A/B tests and conversion lift studies


Create and manage A/B tests (split tests) and conversion lift studies to measure the incremental impact of your ads.

## Discovery

| Tool | Description |
|---|---|
| `ads_experiment_list_tests` | List studies on an ad account, optionally scoped to a specific ad entity or study type. |
| `ads_experiment_check_eligibility` | Check whether an ad account or set of entities is eligible for A/B testing before you try to create one. |

## A/B tests

| Tool | Description |
|---|---|
| `ads_experiment_abtest_create_test` | Create a new A/B test by defining test cells. |
| `ads_experiment_abtest_get_test` | Retrieve details, status, and results of an existing A/B test. |
| `ads_experiment_abtest_update_test` | Edit or cancel an existing A/B test. |

## Lift studies

| Tool | Description |
|---|---|
| `ads_experiment_lift_create_test` | Create a new conversion lift study on an ad account. |
| `ads_experiment_lift_get_test` | Retrieve details, status, and results of an existing lift study. |
