# Help and troubleshooting


Diagnose delivery-blocking errors and look up guidance from Meta Business Help Center.

| Tool | Description |
|---|---|
| `ads_get_errors` | Return delivery-blocking errors for campaigns, ad sets, ads, or an ad account. |
| `ads_get_help_article` | Search Meta Business Help Center for articles about advertising concepts, policies, or troubleshooting guidance. |
